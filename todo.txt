Backend

























Results pagination: Render Next/Prev or “Load more”, wiring to search() with page from backend.







Error Handling

Network errors: Show toast on search() failure; keep previous results visible.
Episode missing audio: If audio element errors after result click, show toast “שגיאת שמע” and keep results selected.




Metrics/Analytics

Track search submit + result click with query, page, result index, and elapsed time.
Optionally log seek timings after episode load.
Optional Enhancements

Batch segment fetch: Use /search/segment/by_idx to prefetch context for visible results.
Result badges: Show folder name, duration from end_sec - start_sec.
Debounced search: Run after idle typing; cancel in-flight requests on new input.
Files To Touch


Acceptance Criteria

Entering a query shows a paginated list of results with folder/file, segment index, start/end time, and a text snippet.
Clicking a result loads its episode, seeks to start_sec, and starts playback; transcript scrolls near the segment and highlights progress as audio plays.
URL ?q=שלום&page=2 opens v2 with results for that query/page.
Errors show a toast without breaking the session; keyboard navigation works.
